# PVT-Testkitchen

Larder: a shared, phone-first tool for food stock, consumables, meal planning, the school snack box and town-trip shopping lists for a farm household.

- `docs/DESIGN.md` — what it is, how it works, the data model and architecture
- `docs/PLAN.md` — phased build plan
- `docs/SETUP.md` — Supabase, GitHub Pages and phone install steps
- `docs/DECISIONS.md` — what was decided when, and why
- `app/` — the Progressive Web App (Vite + Svelte + TypeScript)
- `supabase/migrations/` — database schema

```bash
cd app && npm install && npm run dev
```
